# Online Quiz Application

A simple front-end quiz application built using HTML, CSS and JavaScript.

## Features
- Multiple-choice questions
- Answer selection
- Question progress
- Automatic score calculation
- Final result
- Restart quiz option

## How to Run
1. Extract the ZIP file.
2. Open the folder in VS Code.
3. Open `index.html` in a browser.
4. Select an answer and click Next Question.
5. Complete the quiz to view the score.

## Technologies
HTML, CSS, JavaScript
